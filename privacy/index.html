プライバシーポリシー

制定日：2026年11月11日　／　運営者：せんせい帳 開発者

「せんせい帳」（以下「本アプリ」）における情報の取り扱いについて説明します。

1. 運営者は利用者のデータを集めません

本アプリには運営者のサーバーがありません。入力したデータは、ご利用の端末と、ご自身の Apple ID の iCloud（iCloud のプライベートデータベースと iCloud Drive）にだけ保存されます。運営者がこれらのデータを見たり、受け取ったりすることはありません。

2. 本アプリで扱う情報

  • 教室の情報（教室名、先生のお名前、領収書に載せる住所・インボイス登録番号など、入力した場合のみ）
  • 生徒の名前・ふりがな、保護者の名前、先生のメモ
  • コース、レッスンの予定、出欠、振替、月謝・その他の費用・入金の記録、領収書

生徒の電話番号・住所・生年月日を入力する欄はありません。生徒にはお子さまが含まれるため、保護者の了解のもとで、必要な範囲で入力してください。

3. 同期とバックアップ

iCloud にサインインしている場合、データはご自身の iCloud を通じて iPhone と iPad の間で同期されます。また、毎日1回、ご自身の iCloud Drive（使えない場合は端末内）に自動バックアップを保存し、30日分を保持します。

4. 分析・広告・トラッキング

本アプリは、利用状況の分析、広告、トラッキングのための仕組み（SDK など）を一切使っていません。

5. 購入

有料プランの購入は Apple の App Store を通じて行われます。運営者がお支払い情報を受け取ることはありません。購入状況の確認は端末内で行います。

6. 通知

振替の期限のお知らせは、端末の中だけで作られる通知です。通知には生徒の名前を表示しません。

7. 保護者の方への送信

近況・お知らせ・領収書を保護者の方に送る機能は、先生が内容を確認したうえで、LINE などのアプリを選んでご自身で送るものです。本アプリが自動で外部に送信することはありません。送信した内容の取り扱いは、送信先のサービスの規約に従います。

8. データの削除

アプリの「設定」→「すべてのデータを削除」で、端末と iCloud 上のデータ、および自動バックアップを削除できます。個別の生徒などを削除した場合は「最近削除した項目」に30日間残り、その後完全に削除されます。

9. このポリシーの変更

内容を変更する場合は、このページでお知らせします。

GitHub Issues からお寄せください（生徒さんや保護者の方のお名前など、個人情報は書き込まないでください）。
